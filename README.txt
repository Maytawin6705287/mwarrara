Funeral Fund Club Demo

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or another modern browser.

Demo features:
- Group savings, deposit simulation, emergency withdrawal requests, assistance requests, admin review, activity history, membership plans, and preparedness tools.
- Member Benefits includes sample partner offers. These are fictional demo listings; discounts are not redeemable and no partner agreement is confirmed. Google Maps links open searches so users can check places and distances from a location they choose.
- Family Document Organizer supports emergency contact name and phone number when adding a Contact list record.

Important:
- No real money transfers or assistance payments occur.
- Data is stored only in page memory and resets when the page is refreshed.
- Google Maps requires an internet connection.
